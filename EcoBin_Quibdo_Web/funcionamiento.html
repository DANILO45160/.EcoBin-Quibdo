ENTRADA · PROCESO · SALIDA

¿Cómo funcionaría EcoBin?

El siguiente esquema explica la idea del prototipo. La demostración interactiva es una simulación educativa.

01
📏

Entrada

El sensor ultrasónico mide la distancia entre el sensor y la superficie de los residuos.

02
🧠

Proceso

El microcontrolador interpreta la distancia y estima si la caneca está vacía, a media capacidad o casi llena.

03
🚨

Salida

Se activa una alerta visual y/o sonora según el nivel detectado para indicar que la caneca necesita atención.

PRUEBA INTERACTIVA

Simula el nivel de llenado

Mueve el control para observar cómo cambiaría la alerta. Esta demostración no está conectada a un sensor real.

Nivel normal

La caneca todavía tiene espacio disponible.

Ajusta el nivel o pulsa “Probar alerta”.

Componentes principales

📡

Sensor ultrasónico

Obtiene la distancia hasta la superficie de los residuos.

🔌

Microcontrolador

Procesa la lectura del sensor y decide qué alerta corresponde.

💡

Alertas visuales y sonoras

Luces y sonido pueden avisar cuando la caneca esté próxima a llenarse.
